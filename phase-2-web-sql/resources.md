# Phase 2 Resources

## Required reading

- [MDN — HTML basics](https://developer.mozilla.org/en-US/docs/Learn/Getting_started_with_the_web/HTML_basics)
- [MDN — CSS first steps](https://developer.mozilla.org/en-US/docs/Learn/CSS/First_steps)
- [MDN — HTTP overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) and [HTTP status codes](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status)
- [Tailwind docs — Core Concepts](https://tailwindcss.com/docs/utility-first)
- [The Modern JavaScript Tutorial — Network requests section](https://javascript.info/network)
- [PostgreSQL Tutorial](https://www.postgresqltutorial.com/) — start with "Getting Started", "Querying Data", "Joining Multiple Tables".

## Skip these for now

- React. Phase 4.
- Tailwind v4 migrations / beta features. Use stable.
- Web Components. Out of scope.
- "How browsers work" — interesting but a rabbit hole. After Phase 5 if curious.

## When stuck

- HTML/CSS: MDN. Always MDN first.
- HTTP: the spec is readable. [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110) for the basics.
- SQL: `EXPLAIN ANALYZE` it and stare. Then [Use The Index, Luke](https://use-the-index-luke.com/) if confused about why.
