# Phase 2 Quiz

End of Week 3 (HTML/CSS/HTTP). Week 4 SQL is graded by the kata project. 45 min.

## Section A — HTML (8)

1. What's the difference between `<div>` and `<section>`?
2. Why does every `<input>` need a `<label>`?
3. What does the `<head>` contain that you can't put in the `<body>`?
4. What's the difference between an `id` and a `class`?
5. What happens (by default) when a `<form>` is submitted?
6. Why is `<button type="button">` sometimes necessary?
7. Name 3 input types you'd use that aren't `text`.
8. What does `alt=""` (empty alt) on an `<img>` mean — and when is it appropriate?

## Section B — CSS (10)

1. What's the box model?
2. What does `box-sizing: border-box` change?
3. What's the difference between `margin: auto` and `padding: auto`?
4. When would you use flexbox vs grid?
5. What does `position: absolute` position relative to?
6. What's specificity? Rank `#id`, `.class`, `tag`, and inline styles by specificity.
7. What's the difference between `rem` and `em`?
8. What does `display: none` vs `visibility: hidden` do — and how does each affect layout?
9. What's a Tailwind "utility class"?
10. Why use a design system / token scale (4, 8, 16, …) instead of arbitrary values?

## Section C — HTTP (12)

1. Name the HTTP methods you'd use for: fetching, creating, replacing, partially updating, deleting.
2. What's the difference between status 401 and 403?
3. What's the difference between 301 and 302?
4. What does 422 mean and which framework typically returns it?
5. What does the `Content-Type` header do?
6. What's CORS? What problem does it solve?
7. What does `Access-Control-Allow-Origin: *` mean? When is it dangerous?
8. What does `HttpOnly` do on a cookie?
9. What's the difference between a cookie and `localStorage` for storing an auth token?
10. What does `Cache-Control: no-store` mean?
11. What's a preflight request (`OPTIONS`)? When does the browser send one?
12. You see a request in the Network tab with status 0. What does that mean?

## Section D — Devtools (5)

1. In Chrome devtools, what tab shows you network requests?
2. How do you set a breakpoint in JavaScript from devtools?
3. How do you find the CSS rule that applied a specific style?
4. How do you simulate a slow 3G connection?
5. What does the "Lighthouse" tab give you?

## Section E — Live (15 min)

The mentor shows you a screenshot of a UI. You have 30 minutes to build it in HTML + Tailwind. Should be a one-page, two-section layout: header with logo + nav, hero with image + headline + CTA button.

Grading: works at 360 / 768 / 1440 widths, keyboard-navigable, color contrast passes.

---

**Scoring:**
- A–D: 35 questions, 1 each. Need 28+.
- E: pass/fail.
- Failing → re-do relevant week(s), retake.
