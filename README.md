# Project Prince — A 9-Month Path to Becoming a Real Programmer

**🌐 Live site:** [jakkzz.github.io/prince-curriculum](https://jakkzz.github.io/prince-curriculum/)

A complete, project-based curriculum that takes a beginner from zero to shipping a production AI-powered web app on their own infrastructure.

## Who this is for

A motivated learner (typically a teen or young adult) who has 15–25 hours per week and a mentor available for weekly review.

## What they'll be able to do at the end

- Write, test, and debug code in **Python** and **TypeScript**.
- Build a **FastAPI** backend with **PostgreSQL**, real auth, and tests.
- Build a **Next.js** frontend with TypeScript, Tailwind, and Playwright tests.
- Deploy to an **Ubuntu VPS** with HTTPS, CI/CD, monitoring, and backups.
- Configure **DNS, domains, and Cloudflare** for a production app.
- Integrate **LLM APIs** responsibly — with evals, cost awareness, and safety.
- Work the way professional engineers work: Git, PRs, code review, runbooks.

## Course structure

| Phase | Title | Weeks | Outcome |
|-------|-------|-------|---------|
| 0 | Setup & Habits | 1 | Dev environment + daily commit habit |
| 1 | Python & CLI Foundations | 5 | A real CLI tool with tests |
| 2 | Web Fundamentals & SQL | 4 | Static site + 50 SQL exercises mastered |
| 3 | FastAPI Backend | 6 | Authenticated REST API, dockerized |
| 4 | TypeScript & Next.js | 6 | Full-stack app, frontend deployed |
| 5 | Deployment & Networking | 4 | Live on own domain with CI/CD |
| 6 | A Real Product | 5 | ≥3 real users, full lifecycle |
| 7 | AI Integration | 4 | Capstone — AI feature with evals |

**Total: ~35 weeks of structured work.**

## How each phase works

Every phase contains:

- **`README.md`** — phase overview, learning objectives, gate criteria.
- **`lessons/`** — week-by-week reading and exercises.
- **`project.md`** — milestone project specification with a grading rubric.
- **`quiz.md`** — concept check (separate `quiz-answers.md` for the mentor).
- **`resources.md`** — curated reading, video, and docs links.

## How to use this course

1. **Phases are sequential.** Do not skip ahead. Each gate exists for a reason.
2. **One commit per day, minimum.** Even a typo fix. The habit matters more than the volume.
3. **No AI coding assistants until Phase 7.** Concept explanations are OK from Phase 3 onward. See [resources/ai-policy.md](resources/ai-policy.md).
4. **Mentor reviews PRs weekly.** Code review is part of the curriculum, not a bonus.
5. **A phase is complete only when the gate passes.** Re-do the project if needed. There are no time penalties — only quality gates.

## The reward

Configured at the start of the course (Apple Silicon RAM/SSD are not user-upgradable):

- **Hardware:** MacBook Air M5, 32 GB unified memory / 1 TB SSD. Real spec — the same machine senior engineers buy themselves.
- **Awarded at:** Phase 7 capstone shipped with real users and a written design doc.
- **Adjacent rewards at milestones:** discussed with the mentor; earned at each phase gate.
