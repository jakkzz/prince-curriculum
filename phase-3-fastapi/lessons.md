### Day 2 — Pydantic models

```python
from pydantic import BaseModel, Field

class QuestCreate(BaseModel):
    title: str = Field(min_length=1, max_length=200)
    description: str | None = None
    xp_reward: int = Field(ge=1, le=1000, default=10)

class Quest(QuestCreate):
    id: int
    completed: bool = False
```

- `Field` for validation rules.
- Optional fields with `| None = None`.
- Use a separate model for **creation** vs **representation** — different shapes.

### Day 2 — SQLAlchemy 2.0

```python
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import String, ForeignKey
from datetime import datetime

class Base(DeclarativeBase): ...

class User(Base):
    __tablename__ = "users"
    id: Mapped[int] = mapped_column(primary_key=True)
    email: Mapped[str] = mapped_column(String(255), unique=True)
    hashed_password: Mapped[str]
    created_at: Mapped[datetime] = mapped_column(default=datetime.utcnow)

class Quest(Base):
    __tablename__ = "quests"
    id: Mapped[int] = mapped_column(primary_key=True)
    user_id: Mapped[int] = mapped_column(ForeignKey("users.id"))
    title: Mapped[str]
    completed: Mapped[bool] = mapped_column(default=False)
```

This is the **2.0 style** (typed `Mapped[]`). Don't use the legacy style — different syntax, similar names, lots of footguns.

### Day 3 — Async SQLAlchemy

```python
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker

engine = create_async_engine("postgresql+asyncpg://...")
SessionMaker = async_sessionmaker(engine, expire_on_commit=False)

async def get_db():
    async with SessionMaker() as session:
        yield session
```

Then in endpoints:

```python
@app.post("/quests")
async def create_quest(body: QuestCreate, db: AsyncSession = Depends(get_db)):
    quest = Quest(...)
    db.add(quest)
    await db.commit()
    await db.refresh(quest)
    return quest
```

### Day 5 — Queries and N+1

```python
from sqlalchemy import select
from sqlalchemy.orm import selectinload

# Bad — N+1
users = (await db.execute(select(User))).scalars().all()
for user in users:
    quests = (await db.execute(select(Quest).where(Quest.user_id == user.id))).scalars().all()

# Good — eager-load
users = (
    await db.execute(select(User).options(selectinload(User.quests)))
).scalars().all()
for user in users:
    quests = user.quests   # no extra query
```

Set `echo=True` on the engine during development to see every SQL query and spot N+1.

## Week 3 — Authentication

### Day 1 — Password hashing

```python
from argon2 import PasswordHasher
ph = PasswordHasher()

hashed = ph.hash("mypassword")
ph.verify(hashed, "mypassword")          # True or raises
```

Why argon2 (not bcrypt, MD5, SHA1):
- Memory-hard — resistant to GPU/ASIC attacks.
- Adjustable parameters as hardware improves.
- It's the current winner of the Password Hashing Competition.

**Never store the plain password. Never log it. Never include it in error messages.**

### Day 2 — Registration and login

Build the `/auth/register` and `/auth/login` endpoints. Returns a JWT.

```python
@router.post("/login")
async def login(body: LoginRequest, db: AsyncSession = Depends(get_db)):
    user = (await db.execute(select(User).where(User.email == body.email))).scalar_one_or_none()
    if not user:
        raise HTTPException(401, "Invalid credentials")
    try:
        ph.verify(user.hashed_password, body.password)
    except VerifyMismatchError:
        raise HTTPException(401, "Invalid credentials")
    token = create_access_token(user.id)
    return {"access_token": token, "token_type": "bearer"}
```

**Note:** Same 401 for "user doesn't exist" and "wrong password." Don't leak which one it is.

### Day 3 — JWTs from scratch

Understand what a JWT actually is before using a library.

A JWT is three base64url-encoded JSON blobs separated by dots:

```
<header>.<payload>.<signature>
```

- **Header** — algorithm and type.
- **Payload** — claims (user ID, expiry, etc.).
- **Signature** — HMAC of header + payload using a secret.

```python
import jwt
from datetime import datetime, timedelta, UTC

def create_access_token(user_id: int) -> str:
    return jwt.encode(
        {
            "sub": str(user_id),
            "exp": datetime.now(UTC) + timedelta(minutes=15),
            "iat": datetime.now(UTC),
        },
        SECRET,
        algorithm="HS256",
    )

def decode_token(token: str) -> int:
    payload = jwt.decode(token, SECRET, algorithms=["HS256"])
    return int(payload["sub"])
```

**Common JWT pitfalls** (be ready to discuss with mentor):
- Algorithm confusion (`alg: none` attacks). Always explicitly specify allowed algorithms.
- No expiry. Always set `exp`.
- Storing in `localStorage` (XSS risk). Use HttpOnly cookies if you can.
- Putting sensitive data in the payload — it's signed, not encrypted. Anyone can read it.

### Day 4 — Auth dependency

```python
from fastapi.security import OAuth2PasswordBearer
from fastapi import Depends

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="auth/login")

async def get_current_user(
    token: str = Depends(oauth2_scheme),
    db: AsyncSession = Depends(get_db),
) -> User:
    try:
        user_id = decode_token(token)
    except jwt.InvalidTokenError:
        raise HTTPException(401, "Invalid token")
    user = await db.get(User, user_id)
    if not user:
        raise HTTPException(401, "User not found")
    return user

@router.post("/quests")
async def create_quest(
    body: QuestCreate,
    user: User = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
):
    ...
```

Now every endpoint that needs auth just adds `user: User = Depends(get_current_user)`.

### Day 5 — Refresh tokens and revocation

The 15-minute expiry on access tokens is too short for usability. Add refresh tokens:

- **Access token** — short-lived (15 min), in memory or HttpOnly cookie.
- **Refresh token** — longer (7–30 days), stored in DB with a revocation flag, in HttpOnly cookie.
- `/auth/refresh` endpoint exchanges a valid refresh token for a new access token.
- `/auth/logout` revokes the refresh token.

This is harder than it sounds. Implement it. You will hit edge cases.

### Day 4 — Health checks and readiness

```python
@app.get("/health")
async def health():
    return {"status": "ok"}

@app.get("/ready")
async def ready(db: AsyncSession = Depends(get_db)):
    # check the DB is reachable
    await db.execute(text("SELECT 1"))
    return {"status": "ready"}
```

`/health` = "I'm alive." Always returns 200 if the process is running.
`/ready` = "I can serve traffic." Checks dependencies.

Load balancers use these to decide whether to send you requests.
