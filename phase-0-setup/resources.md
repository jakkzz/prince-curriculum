# Phase 0 Resources

## Required reading

- [Pro Git, Chapters 1–3](https://git-scm.com/book/en/v2) — free online, the definitive reference.
- [The Missing Semester of Your CS Education — Lecture 1 & 2](https://missing.csail.mit.edu/) — MIT's "the stuff they don't teach you in CS class." Watch the first two videos.

## Recommended reading

- [GitHub Flow](https://docs.github.com/en/get-started/using-github/github-flow) — the workflow we'll use the whole course.
- [How to Write a Git Commit Message](https://cbea.ms/git-commit/) — short, opinionated, correct.
- [Atlassian: Learn Git with Bitbucket Cloud](https://www.atlassian.com/git/tutorials) — visual, friendly intro.

## Things you DO NOT need yet

These are popular but irrelevant for Phase 0. Resist:

- Git GUI clients (SourceTree, GitKraken). Learn the CLI first. Use a GUI later if you want.
- "Advanced git" courses. You will not need `git filter-branch` or `git worktree` this month.
- Linux distro tutorials. You're not setting up a server yet.
- Vim or Emacs tutorials. VS Code is fine. Don't go down that rabbit hole this week.

## Typing tools (pick ONE)

- [Monkeytype](https://monkeytype.com/) — most popular, clean interface.
- [keybr.com](https://www.keybr.com/) — adaptive, targets your weak letters.
- [typing.club](https://www.typing.club/) — structured curriculum.

## When you're stuck

In order:

1. [Phase 0 troubleshooting in the main guide](../resources/troubleshooting.md).
2. Search the literal error message in quotes on Google.
3. Ask in your team's Slack / Discord / wherever.
4. Mentor.

Don't skip steps 1–3 on the way to step 4.
