# Phase 0 — Setup & Habits

**Duration:** 1 week (5 working days)
**Prerequisites:** A computer (any), an internet connection, willingness.

## Why this phase exists

Most learners fail not from the hard stuff but from the boring stuff: an environment that doesn't quite work, git habits they never picked up, a typing speed that makes coding feel like punishment. We spend a week getting these right so they never have to think about them again.

## Learning objectives

By the end of this phase, the learner can:

1. Open a terminal and navigate the file system from memory.
2. Create, clone, commit, push, and pull a git repository without looking anything up.
3. Make a pull request on GitHub.
4. Type 40+ wpm on English prose with ≤2% error rate.
5. Explain what each command they ran did, in their own words.

## Tools installed by end of phase

- iTerm2 or Warp (macOS) / Windows Terminal (Windows) / native (Linux)
- VS Code with these extensions only: GitLens, Markdown All in One
- Git, configured with name and email
- SSH key pair, registered with GitHub
- A GitHub account
- A typing tutor of choice (Monkeytype, keybr.com, or typing.com)

**Note:** No language tooling yet. Python and Node come in Phase 1. We don't install what we don't use.

## Time expectations

- **Total this week:** 15–20 hours.
- **Per day:** 3–4 hours.
- **Stuck-on-install budget:** 2 hours max on day 1. If still stuck, get help.

## What the mentor watches for

- Are they actually typing the commands or copy-pasting? Copy-paste in this phase = relearning later.
- Are they reading error messages or just running things again?
- Is the learning log being updated daily, or being backfilled on Friday?
